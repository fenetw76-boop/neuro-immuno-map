# Neuro-Immune Map

An interactive educational website exploring how HIV-related immune activation can affect the central nervous system.

## Research questions
How can persistent immune activation contribute to neurological injury and cognitive impairment in HIV infection?

## How did I come to make this?
I started to question why HIV rebound after ART interruption then this lead me to another question: how can HIV-related immune activation affects central nervous system even when treatment suppresses the virus in the blood?

## Built with
HTML, CSS, JavaScript

## Important note
This project is for education only. It is not medical advice, diagnosis, or treatment guidance.
